Install [vlint](https://github.com/data-intuitive/viash-lint), the
formatter and linter for Viash configs, and add it to the `PATH`.

Installing vlint needs a token with read access to
data-intuitive/viash-lint (a fine-grained token with “Contents:
Read-only”). With `on_missing_token: skip`, a missing token is not an
error and the `installed` output is `false`.

### Inputs available

- `token`: *(Optional)* GitHub token with read access to
  data-intuitive/viash-lint, used to download the vlint release.
  Default: `${{ github.token }}`.
- `version`: *(Optional)* The vlint release tag to install
  (e.g. `v0.0.2`), or `latest` for the latest release. Default:
  `latest`.
- `on_missing_token`: *(Optional)* What to do when the token is empty:
  `error` fails the step, `skip` gives a notice and does not install
  vlint. Default: `error`.

### Outputs

- `installed`: Whether vlint was installed (`true` or `false`).
- `path`: The path to the installed vlint executable.
- `version`: The installed version of vlint.

## Usage

The data-intuitive/viash-lint repository is private, so a secret token
is required for access (here `VLINT_TOKEN`). See [`pro/vlint`](../vlint)
for a workflow that checks the Viash configs, and for how to skip the
check when the secret is not set.

``` yaml
name: Demo of setup-vlint

on:
  push:

jobs:
  demo:
    runs-on: ubuntu-latest

    steps:
    - name: Setup vlint
      id: setup-vlint
      uses: viash-io/viash-actions/pro/setup-vlint@v6
      with:
        token: ${{ secrets.VLINT_TOKEN }}

    - name: Show the vlint version
      run: echo "vlint ${{ steps.setup-vlint.outputs.version }}"
```
